# Design Tokens

Token reference for **Campus X Launchpad**. Use utility classes and CSS variables — never raw values.

## Colors

Apply with any color utility: `bg-<name>`, `text-<name>`, `border-<name>`, `ring-<name>`, `divide-<name>`, etc.

| Name | CSS variable |
|---|---|
| `background` | `--background` |
| `foreground` | `--foreground` |
| `surface` | `--surface` |
| `surface-2` | `--surface-2` |
| `card` | `--card` |
| `primary-foreground` | `--primary-foreground` |
| `secondary` | `--secondary` |
| `muted` | `--muted` |
| `muted-foreground` | `--muted-foreground` |
| `accent` | `--accent` |
| `gold` | `--gold` |
| `gold-muted` | `--gold-muted` |
| `destructive` | `--destructive` |
| `destructive-foreground` | `--destructive-foreground` |
| `border` | `--border` |
| `ring` | `--ring` |
| `overlay` | `--overlay` |
